# ✦ Lunar Cycle — Desktop Companion ✦
*Reading the Stars*

A minimalist, frameless occult desktop companion widget built with Electron that calculates real-time lunar phases, illumination percentages, and lunar zodiac placements.

Designed as part of a triadic desktop companion suite alongside **Daily Arcana** and **Wheel of the Year**.

## ✦ Key Features

- **Astronomical Lunar Ephemeris:** Real-time calculation of current lunar phase (Waning Gibbous, Waxing Crescent, Full, New) and precise moon age in days.
- **Zodiac Sign Mapping:** Tracks the moon's transit through celestial astrological signs (e.g., *Moon in Gemini ♊*).
- **Illumination Telemetry:** Dual-metric layout displaying active surface illumination percentage and day count.
- **Occult Talisman Aesthetic:**
  - Frameless, transparent floating window (`310px` × `365px`) with a draggable title bar.
  - Cohesive design tokens (`#f2e6d8` parchment cream, `#E3C896` talisman gold).
  - Radiant moon orb with layered ambient gold back-glow and outer star compass motifs.

## ✦ Tech Stack

- **Runtime:** Electron
- **Target:** Windows Portable executable (`electron-builder`)
- **Frontend:** Vanilla HTML5, CSS custom properties, SVG accents
- **Typography:** *Cinzel* (titling & zodiac headers), *Lexend* (metrics & telemetry)
